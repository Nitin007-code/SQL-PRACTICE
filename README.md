# SQL Practice — 100 LeetCode Problems

A focused SQL practice repository containing **100 LeetCode SQL problems** across Easy, Medium, and Hard difficulty levels.

The goal is to strengthen SQL fundamentals, problem-solving skills, and interview readiness through consistent practice.

---

## 🎯 Goal

Solve **100 SQL problems** from LeetCode, covering:

- 40 Easy Questions
- 40 Medium Questions
- 20 Hard Questions

Problems will be solved progressively, starting with fundamentals and moving toward advanced SQL concepts.

---

## 📚 What I Will Learn

### SQL Fundamentals
- SELECT
- WHERE
- DISTINCT
- ORDER BY
- LIMIT
- Filtering and conditions
- NULL handling

### Aggregation
- COUNT()
- SUM()
- AVG()
- MIN() / MAX()
- GROUP BY
- HAVING

### JOINs
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- SELF JOIN
- Multiple-table JOINs

### Subqueries
- Simple subqueries
- Nested queries
- Correlated subqueries
- EXISTS / NOT EXISTS

### Advanced SQL
- CASE statements
- CTEs
- Window functions
- RANK()
- DENSE_RANK()
- ROW_NUMBER()
- PARTITION BY
- LAG() / LEAD()

### Problem-Solving Skills
- Breaking down SQL problems
- Choosing the right query structure
- Combining multiple SQL concepts
- Writing clean and efficient queries
- Understanding real-world relational data
